# MapScript — Atlas tiến hóa chữ viết Đông Á

WebGIS tương tác sử dụng Leaflet + CARTO/OpenStreetMap, HTML thuần không cần máy chủ ứng dụng. Mở https://xulytiengviet.github.io/mapscript/ sau khi GitHub Pages đã được bật.

Tính năng: sơ đồ cây ▶ mở/thu, lọc theo niên đại, tìm kiếm, hiển thị tuyến quan hệ, tóm tắt lịch sử, xuất GeoJSON.

Các nhánh **Hán tự**, **Brahmi**, **Sogdian**, **Latin** được phân biệt. Hangul sáng tạo năm 1443, không phải hậu duệ trực tiếp Hanja; Quốc ngữ thuộc hệ chữ Latin. Dấu nét đứt biểu thị ảnh hưởng hoặc liên hệ, không phải kế thừa trực tiếp. Tọa độ, niên đại là đại diện để giáo dục, không phải tuyến di cư khảo cổ.
